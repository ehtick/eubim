# Sentinel: AI-Assisted Automation of AEC Standards and Revit QC

Sentinel is a governed AI-assisted capability factory for BIM/Revit quality control. It turns written standards, owner requirements, and model-quality rules into executable Revit capabilities: checks, fixes, configuration parsers, preview summaries, rollback paths, and audit records.

First of all, it absolutely must satisfy to 100% the top AEC modelling priority: reliablility, governance, liability, trust.

Secondly, Sentinel addresses another core problem: AEC standards are usually written for humans, while BIM models are structured for software. A requirement may live in a PDF, spreadsheet, BIM execution plan, shared-parameter file, IFC mapping table, or owner handover standard. Even when the requirement is clear, someone still has to translate it into Revit reality: category, parameter, unit, stage, exception, source of truth, and safe remediation behavior. Sentinel treats that translation layer as the product.

At a technical level, Sentinel combines:

- AI-assisted interpretation of standards and requirements
- Deterministic Revit API capability generation in C#/.NET
- Owner-specific configuration and disambiguation substrate
- Staged artifact production
- Verification gates that check API usage, parser/code alignment, runtime contracts, and known failure modes
- Human approval boundaries for higher-risk changes
- Receipts, rollback data, and evidence trails for applied fixes

The important point is that Sentinel is not just “AI writes a script.” The AI is embedded inside a governed pipeline. Each generated capability is shaped by explicit prompts, reference documents, catalog entries, runtime contracts, and verifier checks. When ambiguity or defects appear, the lesson is routed back into durable substrate: prompts, schemas, reference docs, design patterns, changelogs, validators, or backlog items.

A simple example is a standards rule that says a project must contain required shared parameters or IFC-related mappings. Sentinel can translate that into a Revit capability that inspects the active model, identifies missing or incorrect setup, previews the proposed correction, applies approved fixes, and records what changed. For design-judgment issues, Sentinel can report or block rather than silently modify the model.

This distinction matters for AEC automation. Many tools can find problems. Sentinel is designed to help move from standards to governed action: inspect, preview, fix where safe, escalate where judgment is required, and preserve evidence.

In short: BIM gave the industry computable building information, but much of the standards interpretation still sits in human memory. AI now makes it possible to accelerate that interpretation, but only if it is governed by provenance, deterministic checks, Revit runtime knowledge, and human approval. Sentinel is our attempt to build that governed translation layer between human standards and computable building information.
