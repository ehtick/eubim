### ChatGpt:

Title

Autonomous Revit Add-Ins: AI-Driven Code Generation, Testing, and Self-Debugging

Synopsis

This talk presents a practical framework for building Revit add-ins that evolve through an autonomous feedback loop. Using RevitTemplates and RevitUnit as the execution backbone, we integrate an AI coding agent to generate Revit API code, run in-process tests, and iteratively fix failures. The key innovation is adaptive instrumentation: the system augments its own logging to expose hidden state, making Revit’s transaction-bound, UI-constrained environment observable and debuggable. We’ll walk through a working setup, demonstrate failure-to-fix cycles, and discuss design patterns that turn Revit into a deterministic, self-improving development platform.

Title

Autonomous Revit Add-Ins: AI-Driven Code Generation and Self-Testing Workflows

Synopsis

This presentation explores how agentic AI can be integrated into a Revit add-in development pipeline to automatically generate, validate, and refine Revit API code. Focusing on a Windows-based setup with Revit running in-process, it demonstrates how a coding agent (e.g., Codex) can iteratively write add-in logic, trigger a test harness such as Nice3point RevitTest, and use structured test results to improve code quality without manual intervention. The talk highlights architectural patterns, orchestration challenges, and practical constraints of Revit’s UI-bound environment, offering a realistic blueprint for semi-autonomous development workflows in BIM software engineering.

Title

Revit Testing Evolved: Choosing Your Engine with Nice3point and ricaun

Synopsis

Unit testing in Revit has historically been a slow, cumbersome process, often leading developers to skip it entirely. This session dives into the modern landscape of Revit testing frameworks, specifically comparing the established NUnit-based approach by ricaun with the cutting-edge TUnit implementation by Nice3point. We will explore how these tools bridge the gap between external runners and the Revit API, automate Revit startup, and handle multi-version compatibility. Attendees will learn how to select the right framework for their team’s needs, resulting in more stable add-ins, faster deployment cycles, and a significantly cleaner codebase.
